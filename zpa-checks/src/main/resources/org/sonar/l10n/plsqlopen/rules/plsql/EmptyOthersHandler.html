A WHEN OTHERS exception handler whose body is empty or contains only a NULL statement silently swallows every error that reaches it, including ones the code was not written to anticipate. The failure disappears without a trace, which makes the resulting bug much harder to diagnose later.

begin
  do_something();
exception
  when others then
    null; -- Noncompliant
end;

Log the error, re-raise it, or handle it explicitly instead:

begin
  do_something();
exception
  when others then
    log_error(sqlerrm);
    raise;
end;

This rule only flags a bare WHEN OTHERS handler (not combined with OR and another exception name). A handler for a named exception, or one combined with OTHERS via OR, is not reported.

A FETCH ... BULK COLLECT INTO without a LIMIT clause loads every remaining row of the cursor into the collection in one step. For a cursor that can return a large or unpredictable number of rows, this can exhaust the session's memory (PGA).

fetch my_cursor bulk collect into my_table; -- Noncompliant

Add a LIMIT clause and fetch the rows in bounded batches instead:

loop
  fetch my_cursor bulk collect into my_table limit 100;
  exit when my_table.count = 0;
  -- process my_table
end loop;
